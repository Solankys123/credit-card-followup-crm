# Credit Card Follow-Up CRM — Android MVP

## Purpose
An Android-first, local/offline personal CRM for managing customer inquiries, application references, follow-ups, documents, issues, daily work queues and productivity.

## Current MVP
- Customer management
- Short/long inquiry classification
- Configurable categories
- Application tracking
- Follow-up reminders
- Call outcomes and notes
- Document checklist
- Issue tracking
- Timeline
- Search/filter
- Daily dashboard
- Basic analytics
- Secure handling of sensitive fields

## Guardrails
- Do not store real customer data in source control.
- Never store CVV, OTPs, passwords or banking credentials.
- Do not bypass, scrape or automate protected banking systems.
- Any future integration must use an officially authorized mechanism.
- Do not put PAN or other sensitive data in notifications or logs.

## Roadmap
1. Android MVP
2. Pilot with synthetic data
3. Productivity automation
4. Growth analytics
5. AI assistant
6. Optional cloud/team version
