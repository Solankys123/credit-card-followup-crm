# Credit Card Follow-Up CRM

Initial product planning document.

## Goal
Build an Android-first personal CRM for customer inquiries, application tracking, follow-ups, documents, issues and daily work queues.

## MVP
- Customer management
- Inquiry classification
- Application tracking
- Follow-up reminders
- Calls and notes
- Documents
- Issues
- Timeline
- Dashboard
- Search and filters
- Basic analytics

## Principle
Build the local/offline MVP first and use only authorized integrations with protected banking systems.
